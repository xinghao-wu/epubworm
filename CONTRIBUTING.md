# Contributing

Thank you for considering to contribute! This project is written in C++23.

## Make Command Reference

| Command | Description |
| --- | --- |
| `make` or `make release` | Build the optimized executable at `build/epubworm`. |
| `make debug` | Build an AddressSanitizer-enabled debug executable at `build/epubworm_debug`. |
| `make test` | Build the debug test executable and run the test suite. |
| `make fmt` | Format all C++ source and header files in `src/` with `clang-format`. |
| `make fmt-check` | Check formatting without changing files. |
| `make fmt-check-diff` | Print a diff for files that do not match the configured format. |
| `make lint` | Run `clang-tidy`. |
| `make lint-fix` | Apply fixes suggested by `clang-tidy` where possible. |
| `make clean` | Remove the `build/` directory and all generated build artifacts. |
| `make install` | Build and install the executable, licenses, and shell completions system-wide. |
| `make install-user` | Build and install under the current user's local prefix (by default, `~/.local`). |
| `make uninstall` | Remove files installed by `make install`. |
| `make uninstall-user` | Remove files installed by `make install-user`. |

Standard Make variables such as `CPPFLAGS`, `CXXFLAGS`, `LDFLAGS`, and `LDLIBS` can be used to add local build options.

Before submitting a change, run:

```bash
make fmt
make lint
make test
make
```

## Clang Tools

The project uses `clang-tidy` and `clang-format`.

## Project Structure

| Path | Purpose |
| --- | --- |
| `fixtures/epubs/` | Zipped and unzipped EPUB fixtures used by tests. |
| `test_outputs/` | Artifacts generated by tests for manual verification. |
| `completions/` | Bash, Zsh, and Fish completion definitions installed with the application. |
| `assets/` | Image and video documentation assets. |
